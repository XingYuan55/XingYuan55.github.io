# 设置

设置窗口集中放账号、外观、模型、插件、Agent 预设这些全局选项。打开方式：点侧栏左下角显示账号的按钮，选 **设置**。窗口右上角有 **打开配置文件** 和 **关闭**。

左侧一列是分组：

- **账号与余额**
- **通用设置**
- **模型**
- **内置插件**
- **电脑操控**（是否出现取决于是否装了对应能力的插件）
- **Agent 预设**

这一列里多出来的分组，通常是第三方插件加的，换台机器可能就没有。

## 账号与余额

先看登录状态：**已登录 DeepSeek**，下面是打码的手机号，点 **更多账号信息** 看完整信息。

再下面是钱：**充值余额** 显示当前余额，**查询用量** 打开用量页面，**充值** 去充值。余额用完了，对话会报错，到这里充。

## 通用设置

按页面上从上到下的顺序：

- **权限**：新会话默认用哪一档权限。点下拉选 **仅可查看**、**工作区内修改** 或 **完全权限**。这项只改新会话的默认值，已经在跑的会话不受影响。
- **语言**：界面语言，中文或 English。
- **外观**：**浅色**、**深色**、**跟随系统**。选跟随系统就跟着 Windows 的深色模式走。
- **字号大小**：只影响会话内容的字号，当前多少 px，右边有 **增大字号**、**减小字号**，还有 **更多字体设置** 可以细调。
- **工作步骤展示**：工具调用细节显示多少，可选 **简洁**、**标准**、**详细**、**完全展开**。
- **工作步骤收起时机**：什么时候自动收起，可选 **回答结束后**、**下次有新消息时**。
- **收起后显示的回复**：收起之后还留着哪些助手回复，可选 **全部回复**、**仅最终回答**。
- **显示代码工作视图**：打开后，轨迹里会显示本轮的代码差异，也能切换完整的 Agent 预设。
- **快捷键**：点 **编辑快捷键** 查看和改当前的快捷键和输入操作。

往下滚还有 **性能与用量**（简洁或详细，决定用量统计展示得多细）和 **网页链接默认打开方式**（在应用内侧边栏打开，或用默认浏览器开）。这两项在不同版本里位置可能变。

## 模型

这里管「AI 用哪家模型」。一行一个提供商：

- **DeepSeek 账号**：绿点表示已登录，直接用账号里的额度。
- **DeepSeek**：填 API 密钥走 DeepSeek 官方 API。
- **Third-Party**：自定义的提供商，带 **编辑** 和 **删除**。

点行可以改配置，底部 **+ 添加模型提供商** 添加新的。这一页只管「能用哪些模型」，具体某个对话用哪个模型，在输入框右下角选。

## 内置插件

和侧栏 **插件** 面板的配置区是同一批东西，这里按「会话插件」列成卡片：智能体角色设定、工作区指令加载、时间感知、命令工具、文件工具、后台任务、任务调度、本地技能加载等，每张卡片能单独开关。

页面顶部可能有 **插件列表** 之类的页签，那是插件加的，不是必备。

## Agent 预设

预设决定一个会话里 AI 能用哪些工具、按什么方式工作。内置四张卡：

- **标准模式**（默认）：处理代码、文件和资料，适合大多数任务。
- **PTC 模式**：在标准模式的能力上加批量调度，适合批量调用工具、再筛选整理的任务。
- **极简模式**：只用终端和图片读取工具，支持上下文压缩，适合测试或对比。
- **创造模式**：给 DSH 定制用，能加新功能或界面。

每张卡下面有 **模式说明** 和 **如何使用**。底部 **让 Agent 帮我创建预设模式**，可以让 AI 按你的描述做一个自定义预设。自建的预设也出现在这一页。

改预设只影响新会话；会话顶部的「标准模式」标签显示的就是它当前用的预设。

## 打开配置文件

右上角 **打开配置文件** 会打开当前 profile 的配置文件。改它要懂格式，改错可能导致 DSH 起不来；不确定时先备份，或者改完用「退出」重开验证。

## 关于「电脑操控」

这个分组只有装了对应的电脑操作插件才会出现（例如让 AI 看屏幕、点按钮、打字）。它不是 DSH 自带功能，开关和风险提示以插件自己的说明为准。没装插件的机器上，这里没有这一项。
