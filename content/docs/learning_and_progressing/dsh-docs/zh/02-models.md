# 模型与推理等级

用 DeepSeek 账号或 API Key，也可以接入任何 OpenAI 兼容的服务。凭据由应用统一保管，存在本机 `.dsh\.credentials.yaml` 里，不写进会话内容；模型和密钥在设置里配置，见本文末尾的「设置里的模型页」。

## 切换模型和推理等级

在输入框下方点 **选择模型** 按钮，打开「模型与推理等级」弹层：

- 顶部是 **搜索模型…**，输入名称过滤。
- 中间按提供商分组，例如 **DeepSeek 账号**、**DeepSeek**、**Third-Party**。每一组里列出这个提供商的模型，前面的圆点是当前选中的。
- 点一个模型立即切换并关闭弹层。
- 弹层最下面一行是 **推理等级**，显示当前档位，如 `High`。点开选档位；模型支持哪些档位由提供商和模型决定。

输入框下方那枚按钮会显示当前状态，例如 `DeepSeek-V4.1-Flash High`：斜杠前是模型，后面是推理等级。切换只影响这个会话接下来的生成，已经生成的内容不会重写。

## 推理等级

推理等级决定模型在回答前想多久。常见的几档：

- **不思考**：直接回答，最快。模型支持关闭思考时才出现。
- **低 / 中 / 高**：档位越高，思考越长，通常也更慢、更贵。
- **更高档位**（如 `xhigh`、`max`）：只有部分模型提供。

选哪一档没有绝对标准：代码、数学、长文分析用高一些；闲聊、改写、查个名字用低一些甚至不思考。不确定就先用默认档。

## 新会话默认

新会话打开时显示的是配置里的默认模型（配置项 `agent-default-model`）。在会话里换模型只影响这个会话，不会改默认值；想改所有新会话的默认，改配置文件后重启应用，见 [设置](08-settings.md) 的「打开配置文件」。

## 设置里的模型页

<!-- nav: settings,models -->
`账号菜单 › 设置 › 模型`

页面开头一句说明：「填入各提供商的 API 密钥即可使用其模型。」下面按提供商列出：

- **DeepSeek 账号**：已登录时显示绿点和「已登录」，用账号直接调用，不需要填 Key。
- **DeepSeek**：填 API Key 用 DeepSeek 开放平台的模型。右侧 **编辑** 改 Key。
- **Third-Party** 一类：来自配置文件或你添加的提供商，标注「自定义」，右侧 **编辑**、**删除**。
- **+ 添加模型提供商**：新增一个提供商，填名称、API 地址、API Key，再选或手填模型 ID。

删掉一个提供商，它的模型立刻从模型选择里消失。正在用它的会话需要换模型才能继续。

## 模型和凭据存在哪

配置在 profile 目录里，不在应用安装目录：`%USERPROFILE%\.dsh\profiles\desktop\` 下的 `package.json` 与 `cordis.patch.yml`，API Key 等凭据单独存放在 `.dsh\.credentials.yaml`。改这些文件前先退出应用，改完重启才生效；直接编辑可能让应用读不到配置。

不记得自己加过什么提供商时，用 [设置](08-settings.md) 的「打开配置文件」查看当前生效的配置。
