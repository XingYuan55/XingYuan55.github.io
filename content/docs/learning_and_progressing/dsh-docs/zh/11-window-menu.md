# 窗口与菜单

DSH 是桌面应用，除了界面里的按钮，还有窗口顶部的一排菜单。这一章讲菜单、窗口行为和快捷键。

## 应用菜单

点左上角的 **应用**，从上到下：

- **关于 DeepSeek Harness**：版本号和说明。
- **检查更新…**：检查有没有新版本。
- **管理 dsh 命令…**：管理命令行入口。
- **开发者工具**：打开调试面板，快捷键 Ctrl+Shift+I。排查问题时用，正常用不到。
- **退出**：关掉 DSH。

**退出** 会结束 DSH 进程。正在跑的任务会中断，没发出去的消息会留在输入框草稿里，下次开还可能在。

## 编辑菜单

- **撤销** Ctrl+Z
- **重做** Ctrl+Y
- **剪切** Ctrl+X
- **复制** Ctrl+C
- **粘贴** Ctrl+V
- **删除**
- **全选** Ctrl+A

这些是输入框和文本区域的编辑操作，Windows 上通用的那套。

## 窗口

- 右上角三个按钮：最小化、最大化、关闭。
- 关窗口不等于退出进程；再打开时状态还在。
- 窗口大小、位置会被记住，下次打开回到上次的大小。

## 快捷键

常用的有：

- **Ctrl+P**：打开工作区文件。
- **Ctrl+\`**：新建终端。
- **Ctrl+T**：打开内置浏览器。
- **Ctrl+Shift+I**：开发者工具。
- **Esc**：关弹层、取消输入。输入框里连续按两次 Esc，可以停止生成。

快捷键能改：设置 → 通用设置 → **编辑快捷键**。改过的存在本机，跟着这台机器走。

不同版本快捷键可能变，以 **编辑快捷键** 里列出的为准。

## 视图

顶栏右侧的 **更多会话视图** 是页签列表的展开项。**用文件资源管理器打开** 打开当前工作区文件夹。**更多打开方式** 用其它编辑器打开同一个文件或目录。**更多操作** 是会话级的动作：复制会话为 Markdown、下载 Session 日志、反馈。

## 外观

窗口跟系统主题走还是固定浅色深色，在设置 → 通用设置 → **外观** 里选。侧栏和右侧工具区都能收起、展开，见「外观与显示」。
