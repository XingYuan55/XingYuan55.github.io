# 外观与显示

外观相关的东西散在设置里和窗口菜单里，这一章集中说。入口：侧栏左下角账号按钮 → **设置** → **通用设置**。

## 主题

三个按钮：**浅色**、**深色**、**跟随系统**。

跟随系统指跟着 Windows 的深色模式切换。选它之后，系统切夜间模式，DSH 也跟着变。只在 DSH 里切，别的地方不受影响。

## 字号

**字号大小** 只改会话内容的字号，不改侧栏和后台界面的字号。当前值写在旁边，例如 14 px。右边两个箭头：**增大字号**、**减小字号**。

更细的调整点 **更多字体设置**，那里能分别调界面和代码的字号字体。调大了能看到更多字、每屏更少内容，调小了相反。

## 工作步骤显示多少

会话里每一步工具调用都会显示成一行。显示多少由 **工作步骤展示** 决定：

- **简洁**：只留结果，过程折叠。
- **标准**：重要步骤留一行，细节折叠。
- **详细**：每个调用都显示，参数可以展开。
- **完全展开**：全部展开，什么都不折。

配合 **工作步骤收起时机**（回答结束后、下次有新消息时）和 **收起后显示的回复**（全部回复、仅最终回答），可以决定回头看对话时屏幕上还剩多少东西。

## 代码工作视图

打开 **显示代码工作视图** 后，轨迹里会显示本轮改了哪些代码的差异，也能在会话里切换完整的 Agent 预设。

改代码多的任务建议打开；只看结论的建议关掉，屏幕更干净。

## 侧栏

侧栏可以收起。侧栏顶部有个收起按钮，收起后内容区变宽，右侧中间会出现展开的按钮。窗口比较窄时，收起侧栏看对话更舒服。

侧栏里工作区和会话怎么排，在 **视图选项** 里调：分组方式（按工作区、按工作区树、单列表）、排序方式（手动排序、最近更新）、筛选（隐藏已归档、全部对话、仅显示已归档）。

## 右侧边栏

顶栏右边的 **打开右侧边栏** 会在右边开一列，放文件浏览器、终端、内置浏览器这些并排看的东西。用完再点一次关掉，或者拖边框调宽度。

## 什么时候会变样

外观和显示这两类设置，改动立即生效，不影响正在跑的对话。只有一项要注意：字号和主题是全局的，动完所有会话都变。

如果某个界面元素的样子和这里写的不一样，先看是不是装了改界面的插件；插件能注入主题、按钮和面板。
