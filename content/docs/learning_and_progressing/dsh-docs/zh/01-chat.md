# 对话

提问、让 AI 干活、看它每一步做了什么。对话属于当前工作区：换了工作区，列表里就是那个工作区的会话。

## 输入框

窗口底部是输入框，提示文字是「发消息或创建任务, / 调用指令, @ 文件或对话」。写完按发送键；AI 生成时发送键变成**停止**，点它停下当前这一轮。

输入框左侧的 **+** 是「添加文件或调用指令」：把文件、文件夹拖进窗口，或从磁盘选文件，也可以在这里打开指令列表。

输入框下方两个按钮各自管一件事：

- **访问模式**：当前是「仅可查看」「工作区内修改」还是「完全权限」，点开切换，见 [权限与授权](03-permissions.md)。
- **选择模型**：显示当前模型和推理等级，如 `DeepSeek-V4.1-Flash High`，点开切换，见 [模型与推理等级](02-models.md)。

## 指令与引用

在输入框输入 `/` 打开指令列表，输入 `@` 引用文件或别的对话。指令按当前装的插件和设置出现，弹层里列的就是全部可用项。

## 视图：对话、轨迹与更多

会话顶栏下方的 **对话**、**轨迹** 切换这个会话的视图：

- **对话**：你和 AI 的消息，以及 AI 的工作步骤。
- **轨迹**：按时间排的全部请求、工具调用和事件，适合查细节，见 [工作步骤与轨迹](04-work-steps.md)。

标签右侧的 **⋯** 是「更多会话视图」，插件装进来的其他视图也在里面。

## 状态条

输入框下方一行小字是当前会话的状态，从左到右：

- **9 轮 101 步 · 240 tok/s**：已经聊了几轮、AI 走了多少步、生成速度。
- **6.8M tok · 缓存命中 82%**：这个会话累计消耗的 token，以及其中命中缓存的比例。
- **上下文已用 11%**：当前上下文窗口用了多少。

点 **上下文已用** 会打开上下文视图。它由 billion-context 插件提供，不是应用自带页面；卸载插件后这个按钮就没有了。

## 工作步骤

AI 干活时，每一步以一行小字显示在回答上方，例如「思考」「已调用工具并读取文件」「正在操作」「查看了屏幕」，完成后标「已完成」。点一行可以展开细节，展开后能看到这一步的说明和截图。

步骤多的时候会自动收起，只留结果。什么时候收、收多少，在 [设置 › 通用设置](08-settings.md) 里改：

- **工作步骤展示**：简洁 / 标准 / 详细 / 完全展开。
- **工作步骤收起时机**：回答结束后 / 下次有新消息时。
- **收起后显示的回复**：全部回复 / 仅最终回答。

## 顶栏

会话顶栏从左到右：

- **会话层级**：面包屑，显示工作区和会话，点上级回到工作区。
- **标准模式**：这个会话用的 Agent 预设，见 [设置 › Agent 预设](08-settings.md)。
- 右上角的图标：**用文件资源管理器打开**（打开这个会话的工作目录）、**更多打开方式**、**更多操作**、**打开右侧边栏**（见 [右侧边栏与工具](10-sidebar-tools.md)）。

**更多操作** 里有：**复制会话为 Markdown**、**下载 Session 日志**、**反馈**。复制和下载都在本机完成，不会把内容发出去；反馈会把问题带到官方反馈入口。

## 生成中

生成时：

- 发送键变成**停止**，点一下结束这一轮。
- 工作步骤一行行往上冒，点「正在操作 ▾」能看到实时细节。
- 这一轮的用时和速度显示在步骤下方，例如「深度求索中，用时 2分8秒」。

停止后已产生的回答和工作步骤都留在对话里，可以继续追问。
