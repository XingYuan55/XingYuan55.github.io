# 插件

插件面板管三件事：内置功能开不开、实验功能要不要试、第三方插件装了哪些。点侧栏的 **插件** 打开，页头是标题和说明，右上角有 **刷新** 和 **添加插件**。

页面上的东西可能随版本和已装插件变化。看到不认识的分组、开关或页签，多半是某个第三方插件自己加的，不是 DSH 自带。

## 内置插件配置

这一组是 DSH 自带、可以调的几项能力：

- **子智能体**：AI 可以派子任务去做，这里调子智能体的层级和数量。
- **网页搜索**：设置 DeepSeek 的搜索提供方，决定 AI 上网查资料时用哪个搜索。
- **Agent 循环**：控制 AI 一直干到什么时候停，也就是连续调用工具的方式。
- **终端**：限制终端命令最多跑多久、最多输出多少内容。

点进去改，改完生效。前两项影响面大：子智能体开太深会让任务变慢、变贵；搜索提供方定错，AI 会说「搜不到」。

## 实验性插件

这些是还在试的功能，默认关着，右上角有 **实验性** 标签。开关自己打，不保证稳定，也可能在以后的版本里换掉。

常见项：

- **智能体团队**：让 AI 把活分给几个有名有姓的队友，在共享任务列表上跟进度。
- **语音输入**：在手机端用系统语音转写，第一次用时要装依赖。
- **自定义插件索引**：在插件页加一个「发现」页签，从你自己加的索引里浏览和安装插件。
- **自动授权审查**：AI 每次调用工具前，由模型按你的要求先审一遍，通过的立即跑，被拒的等你批。
- **变更请求与工作表**：在会话侧栏里跟进关联的 GitHub PR，看检查状态、评审意见和代码差异。

右上角的「更多」里还有其它实验项。实验性开关点完就生效，不需要重启。

## 已安装插件

这里列出当前装着的所有插件，每个有名字、一句说明和一个开关。关掉的插件不加载，但它写出来的东西（技能、命令、面板）会一起消失。

- **刷新**：重新读一遍插件状态，刚在外部装完插件时点它。
- **添加插件**：按名字或来源安装。

装插件会改这个 profile 的依赖和配置，装完一般要重启 DSH 才对所有界面生效。装之前先看清它是干什么的、是谁的；插件能改你的界面、读你的会话、调你的工具。

## 哪些是第三方加的

第三方插件可以往界面里塞入口：设置窗口里多一页、侧栏多一个面板、输入框上多一个按钮、页签里多一个视图。这些东西进不去 DSH 自带文档，因为换个 profile 或卸载插件就没了。

判断办法：卸载或关掉那个插件，入口消失的就是它加的。写教程、截图、截屏提问时都要留意，别把插件界面当官方界面。
