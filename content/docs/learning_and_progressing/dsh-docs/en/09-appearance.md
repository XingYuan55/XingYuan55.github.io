# Appearance and display

Appearance options live in Settings and in window controls. Entry: the account button at bottom-left → **设置** → **通用设置**.

## Theme

Three buttons: **浅色** (light), **深色** (dark), **跟随系统** (follow system).

"Follow system" tracks Windows' dark mode: switch the OS to night mode and DSH follows. It changes DSH only, not other apps.

## Font size

**字号大小** changes chat content only, not the sidebar or back-office UI. The current value sits next to it, e.g. 14 px. The arrows are **增大字号** (larger) and **减小字号** (smaller).

**更多字体设置** (more font settings) opens finer control over UI and code font sizes and families. Larger means more legible but less per screen; smaller is the opposite.

## How much of the work steps you see

Each tool call shows as one line. **工作步骤展示** decides how much:

- **简洁** (concise): results only, process folded.
- **标准** (standard): important steps keep one line, details fold.
- **详细** (detailed): every call shows, arguments expand.
- **完全展开** (fully expanded): everything open, nothing folds.

Together with **工作步骤收起时机** (fold after the answer / on the next message) and **收起后显示的回复** (all replies / final answer only), you control how much remains on screen when you scroll back.

## Code working view

Turning on **显示代码工作视图** shows this turn's code diff in the trace and lets you switch full Agent presets in the chat.

Turn it on for code-heavy work; leave it off if you only want conclusions and a cleaner screen.

## Sidebar

The sidebar collapses. The collapse button sits at the top of the sidebar; once collapsed the content area widens and an expand button appears mid-right. On narrow windows, collapsing makes chatting more comfortable.

Workspace and chat arrangement is under **视图选项**: grouping (by workspace, by workspace tree, single list), sorting (manual, recently updated), filtering (hide archived, all chats, archived only).

## Right sidebar

**打开右侧边栏** in the header opens a right column for file browser, terminal, and built-in browser side by side. Click the header button again to close it, or drag the divider to resize.

## When things look different

Appearance and display changes apply immediately and do not affect running chats. One caution: theme and font size are global, so changing them changes every chat.

If an element looks different from this guide, first check whether a plugin that changes the UI is installed; plugins can inject themes, buttons, and panels.
